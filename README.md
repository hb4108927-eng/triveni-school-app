# TRIVENI CHILDREN'S ACADEMY — APP V2

Prototype includes:
- Animated school-logo splash screen
- Student / Teacher / Admin roles in one app
- Classes 1–8
- Student profile, marks, attendance, date sheet and timetable
- Teacher class-restricted attendance, marks, date sheet and timetable
- Admin student and teacher management
- Attendance percentage calculations
- Automatic current date/time
- Local browser database using localStorage
- Mobile responsive UI and PWA manifest

IMPORTANT:
This is a front-end prototype. It is NOT yet a production online school system. For real deployment, replace localStorage with a secure server database and authentication, add password hashing/session management, role permissions, backups, audit logs and HTTPS.

Open index.html to preview.
